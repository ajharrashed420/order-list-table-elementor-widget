Display WooCommerce orders and products in modern, customizable Elementor tables with mobile layouts, product filters and Load More.

== Description ==
Build attractive order activity and product catalog tables directly in Elementor. Choose Order List Table (Modern), Order List Compact Table or Product List Table from the Order List Table widget category.

= Features =
* ✅ Three dedicated widgets: Modern Order Table, Compact Order Table and Product List Table.
* ✅ Drag-and-drop columns: reorder fields, edit headings and show or hide individual columns.
* ✅ Responsive layouts: mobile cards, optional sticky headers and adjustable row spacing.
* ✅ Product catalog details: images, titles, prices, linked category thumbnails, sales counts, stock and optional SKU/rating columns.
* ✅ Flexible product filters: select multiple categories, search for specific products, or display Featured, Best Selling, Recent and Best Reviewed collections.
* ✅ Load More on every table: append the next batch without replacing existing rows; customize button text, visibility and appearance.
* ✅ Smart Buy Now links: available simple products open checkout; variable products open their product page for variation selection.
* ✅ Expandable orders: show the first product and reveal additional products with their matching actions.
* ✅ Elementor design controls: customize typography, title and price colors, borders, spacing, images and badge/button corners.
* ✅ Animated details: optional entrance/hover effects, a rotating processing icon and an animated sales fire icon, with reduced-motion support.
* ✅ Stock-out badges: editable text, colors and responsive radius, following the Buy Now radius by default.
* ✅ Privacy and compatibility: masked public customer details, customer/manager order views, HPOS support and native-lazy thumbnails compatible with Click Shop.

= Simple Setup =
Choose a widget, configure the order or product filters, arrange the columns and style the table in Elementor. Modern Design appears first in the Style tab; Load More Button appears last.

Set the items per page to control each batch. For example, 10 displays the first 10 matching rows. Load More appears only when additional results exist and hides after the final batch.

Product price color applies to ordinary prices, variable price ranges and current sale prices. Del Color controls crossed-out old prices. Product and category title colors have separate hover/focus controls, and product titles have an adjustable word limit.

= Order Visibility =
Public order tables mask customer names and phone numbers. Customer-only views require sign-in; manager-only views require WooCommerce management permission. Enabled product, status, date and order-total fields remain public in public activity tables.

Exclude pages with private order views from server/CDN full-page caching. Only published, publicly viewable products are linked, and catalog tables respect WooCommerce catalog and stock visibility.

== Installation ==
1. Install and activate Elementor and WooCommerce.
2. Upload the plugin ZIP through Plugins > Add New, or upload its folder to wp-content/plugins.
3. Activate Order List Table Elementor Widget for WooCommerce.
4. Edit a page in Elementor and open the Order List Table widget category.
5. Add a widget, configure its content and design, then publish or update the page.

== Frequently Asked Questions ==

= Which plugins are required? =
Elementor and WooCommerce must be installed and active.

= Can I reorder or hide columns? =
Yes. Use Drag & Drop Field Order in the order tables or Drag & Drop Columns in the product table. Existing Hide/Show controls also apply.

= Can I display selected products or categories? =
Yes. Search and select multiple categories or specific products in Product Settings. Collection, product-type and stock filters can be combined with these selections.

= How do Buy Now links work? =
Available simple products add one unit and open checkout. Variable products open their product page for variation selection. Grouped/external products use View product links. Existing cart contents are preserved.

= How do I change the stock-out badge radius? =
Open Style > Stock Out Badge > Border radius. Leave it empty to follow the Buy Now radius, or set separate desktop, tablet and mobile values.

= Can animations be disabled? =
Yes. Disable the individual effects in Elementor. Visitor reduced-motion preferences are also respected.

= Will existing order tables keep working? =
Yes. The original widget identifier and supported saved settings are retained.
